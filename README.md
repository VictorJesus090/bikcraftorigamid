Tecnologias usadas

HTML

Estruturação da página com tags semânticas como header, article, section e footer, mantendo o conteúdo bem organizado e alinhado.

CSS

Estilos separados em arquivos diferentes e importados dentro do style.css principal, pra não deixar tudo bagunçado em um arquivo só. Uso bastante display flex e display grid pros layouts, além de variáveis CSS pra cores e fontes, o que ajuda a manter o padrão visual do site inteiro.

Git

Uso o Git Bash direto pelo terminal do VSCode pra subir e atualizar o projeto no GitHub. A cada parte que termino, faço o processo de add, commit e push.

Sobre o JavaScript

Ainda não usei JavaScript nesse projeto. Já vi o básico no curso, mas como esse projeto é focado em fixar HTML e CSS, deixei o JS pra uma próxima etapa.
